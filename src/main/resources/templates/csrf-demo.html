🌐 AJAX请求示例

使用JavaScript发送带CSRF Token的AJAX请求：

// 方式1：从隐藏字段获取Token
const csrfToken = document.getElementById('form_csrf_token').value;

fetch('/transfer/safe-header', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/x-www-form-urlencoded',
        'X-CSRF-Token': csrfToken  // 在请求头中携带Token
    },
    body: 'toAccount=test&amount=100'
})
.then(response => response.json())
.then(data => console.log(data));

// 方式2：从Cookie获取Token
function getCsrfTokenFromCookie() {
    const cookies = document.cookie.split(';');
    for (let cookie of cookies) {
        const [name, value] = cookie.trim().split('=');
        if (name === 'CSRF_TOKEN') {
            return value;
        }
    }
    return '';
}

🎭 CSRF攻击模拟演示

下面演示攻击者如何诱导用户执行非预期的转账操作

攻击步骤：

  1. 用户登录银行网站 → 获得Session
  2. 攻击者诱导用户访问恶意网站
  3. 恶意网站自动向银行发送转账请求
  4. 如果没有CSRF防护 → 转账会被执行 ❌
  5. 如果有CSRF防护 → Token验证失败，转账被拒绝 ✅
