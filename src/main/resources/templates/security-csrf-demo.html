🌐 AJAX请求示例

测试1：带有效CSRF Token的AJAX请求（应该成功）

// 从meta标签获取CSRF Token const csrfToken = document.querySelector('meta[name="_csrf"]').getAttribute('content'); const csrfHeader = document.querySelector('meta[name="_csrf_header"]').getAttribute('content'); fetch('/security/api/transfer', { method: 'POST', headers: { 'Content-Type': 'application/x-www-form-urlencoded', [csrfHeader]: csrfToken // 在请求头中携带Token }, body: 'toAccount=ajax_test&amount=50' })

测试2：带无效CSRF Token的AJAX请求（应该失败）

// 使用无效的Token fetch('/security/api/transfer', { method: 'POST', headers: { 'Content-Type': 'application/x-www-form-urlencoded', 'X-CSRF-TOKEN': 'invalid-token-xyz' // 无效的Token }, body: 'toAccount=hacker&amount=9999' })

🎯 Spring Security CSRF防护特性

🔒 自动化防护

框架自动处理Token的生成、存储和验证，开发者无需手动编写验证逻辑。

🚫 验证失败阻止

当Token无效或缺失时，直接返回403错误，请求根本不会到达控制器。

🎲 强随机数生成

使用SecureRandom生成密码学安全的随机Token，确保Token不可预测。

🍪 Cookie存储

Token同时存储在Session和Cookie中，支持多种验证方式。

⚙️ 灵活配置

可以通过ignoringRequestMatchers配置某些接口忽略CSRF验证。

📝 详细日志

CSRF验证失败时会记录详细的日志信息，便于排查问题。
