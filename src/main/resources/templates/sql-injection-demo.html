🎭 SQL注入攻击模拟演示

下面演示攻击者如何利用SQL注入漏洞获取敏感信息

攻击步骤：

  1. 攻击者发现用户ID参数可能存在SQL注入漏洞
  2. 尝试输入 1 OR 1=1 来测试是否存在漏洞
  3. 如果返回所有用户数据，说明存在SQL注入漏洞
  4. 使用 UNION SELECT 来获取其他表的数据
  5. 最终可能获取用户名、密码等敏感信息

🔴 常见SQL注入攻击示例：

1. 布尔盲注： 1 AND 1=1 / 1 AND 1=2
2. 联合查询注入： 1 UNION SELECT username, password FROM users
3. 时间盲注： 1 AND SLEEP(5)
4. 堆叠查询： 1; DROP TABLE users--
